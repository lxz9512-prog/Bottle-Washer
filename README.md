# 清洗机系列

从原始项目导入的清洗机交互 Demo，已支持独立本地预览，并移入「异常控制台- FD04」对话中的通用演示工具能力。清洗模式、运行控制、设备设置、宝宝物品及通知仍沿用清洗机自身页面，不包含 FD04 调奶、喂养或单位换算业务。

## 本地预览

需要 Node.js 22+、npm 10+：

```sh
npm ci --ignore-scripts
npm run dev
```

默认地址为 http://127.0.0.1:5173/。开发服务器已占用该端口时，Vite 会选择下一个可用端口，以终端输出为准。导入项目中的平台安装脚本不适用于独立预览，因此安装依赖时使用 `--ignore-scripts`。

## 两种体验

- `/#/demo`：桌面演示工作区，保留页面目录、异常控制台、交互说明和可选手机边框。顶部手机图标打开手机体验二维码。
- `/#/app`：手机纯 App 体验，没有异常控制台、模拟手机外壳、信号栏、灵动岛或底部横条；使用设备自身的安全区。页面支持浏览器返回、直接链接和刷新，语言、主题、物品及运行状态在本机保存。
- 不指定入口时，首次根据窗口宽度选择手机（768px 及以下）或桌面体验。入口固定后，旋转屏幕不会切换体验。
- 两种体验共享业务组件，但使用独立存储命名空间 `BW05S_demo_v1:` 和 `BW05S_app_v1:`，异常注入只在桌面演示中启用。
- PC 顶部提供“PC 版／移动版”切换，切换重载实例并保留适用的机型和业务路径，运行数据不跨入口复制；通知页切换到手机版时回到设备列表。
- 明确打开手机版时，1024px 及以上宽屏显示顶部切换栏及无外壳的 393 × 852px 参考预览，高度不足时外层滚动，不缩小界面。1024px 以下铺满可用视口，不显示顶部切换栏。
- 首页包含 BW05S、BW05P、BW05A 三个机型，能力差异与独立链接见 [多型号说明](docs/multi-model-demo.md)。

手机与电脑连接同一 Wi-Fi 时，运行：

```sh
npm run dev -- --host 0.0.0.0
```

手机打开 Vite 输出的局域网地址并加上 `/#/app`。开发模式下，本机访问的二维码会使用检测到的局域网 IP；多网卡或 VPN 环境可直接使用 Vite 输出的有效地址。电脑需要保持运行，防火墙需允许局域网访问。

## PWA 与发布

生产构建包含 Web App Manifest、应用图标和离线缓存。部署到 HTTPS 托管后，手机可通过浏览器「添加到主屏幕」以独立窗口打开；不需要 App Store、开发者证书或安装包。首次联网打开并完成缓存后，可离线重新访问。新版本等待旧页面关闭后启用，不中断正在体验的流程。

局域网 HTTP 仅用于浏览器预览，不能代替 HTTPS 的安装和离线能力。`localhost` 可用于电脑上的 PWA 验证。所有操作仍为模拟，不连接真实清洗机。

项目托管于独立 Cloudflare Worker **bottle-washer**（项目名称 Bottle-Washer），静态产物为 `dist/`，交互说明由同域 API 和专属 D1 数据库保存。GitHub 继续保存源代码，推送 `main` 只执行检查，不再生成 GitHub Pages 页面。原 Pages 项目保留，新的访问入口如下：

- Git 仓库：https://github.com/lxz9512-prog/Bottle-Washer
- 桌面演示：https://bottle-washer.lxz9512-prog.workers.dev/#/demo
- 手机体验：https://bottle-washer.lxz9512-prog.workers.dev/#/app

PC 交互说明点击“编辑”，输入编辑密码即可解锁并保存到线上。编辑会话有效期 12 小时，点击“锁定编辑”可退出。同页并发修改会提示冲突并保留草稿，不会直接覆盖他人的更新。离线可继续体验已缓存 Demo，说明读写需要联网。

Cloudflare 资源配置及维护见 [Cloudflare 部署说明](docs/cloudflare.md)。发布需收到明确指令后执行 `npm run deploy:cloudflare`。
```sh
npm run build
npm run preview
npm run type:check:client
npm run test:demo
npm run test:demo:e2e
npm run test:demo:safe-area
npm run test:app:e2e
```

浏览器回归需要已安装 Google Chrome 和运行中的本地服务器。可通过 `DEMO_URL` 指定桌面测试地址，通过 `APP_URL` 指定手机测试站点根地址。生产预览时设置 `PWA_TEST=1` 可验证离线重新访问。macOS 上自动启动 Chrome 需具备桌面服务访问权限；测试使用独立浏览器上下文，不读取普通浏览器会话。

## 通用演示能力

- 页面目录、当前页交互说明、说明与手机元素之间的连线。
- 手机外的语言、外观、连线及重置工具。
- 可隐藏、折叠的异常控制台；桌面侧栏与窄屏底部抽屉。
- 选择异常立即展示，不设置「稍后触发」开关。
- 页面对应异常及全局模拟断网、弱网。
- 重试成功或仍失败、取消操作、恢复正常、当前环节重置、整个 Demo 重置。
- 保存失败保留输入；重试成功仅提交一次。切页、取消、重置会取消未完成的演示操作。
- 本地持久数据使用 `BW05S_demo_v1:` 命名空间；重置整个 Demo 不清除其他项目的浏览器数据。

## 场景覆盖

| 页面/环节 | 异常 |
| --- | --- |
| 设备列表 | 持续加载、空列表、加载失败 |
| 模式选择 | 启动失败、响应超时 |
| 运行控制、智能模式 | 控制失败、连接中断 |
| 设备信息 | 名称保存失败 |
| 宝宝物品编辑 | 保存失败、模拟校验不通过 |
| 已接入操作的页面 | 模拟断网、弱网 |

本地配置与说明页面不虚构请求。正常设备列表不增加「重新加载设备」入口。原有确认、编辑弹层保留，演示异常以内联状态展示，不引入 FD04 专属故障弹窗。

## 实现边界

- `client/src/demo/catalog.ts`：页面、操作、说明和异常场景契约。
- `client/src/demo/engine.ts`：单一模拟操作边界、重试和定时器取消。
- `client/src/demo/react.tsx`：页面接入、操作注册、重置和状态展示。
- `client/src/components/Layout.tsx`：独立演示工作区。
- `tests/engine.test.mjs`：场景和恢复规则测试。
- `tests/demo.e2e.mjs`：桌面与 375/390/430 像素窄屏浏览器回归，截图输出到忽略版本控制的 `tests/artifacts/`。

异常和网络均为前端模拟，不连接真实设备、账户或系统权限，交互说明读写使用项目自己的云接口。当前体验页面引用的产品图、背景、监控预览与模式图标均随项目打包，不依赖远程图片。
